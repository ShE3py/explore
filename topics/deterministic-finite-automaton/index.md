A **deterministic finite automaton** (DFA) is a [finite-state machine](https://github.com/topics/finite-state-machine) that accepts or rejects a given string, by running through a state sequence uniquely determined by the string.
*Deterministic* refers to the uniqueness of the computation run, i.e. each of its transitions is uniquely determined by its source state and input symbol, and reading an input symbol is required for each state transition.
